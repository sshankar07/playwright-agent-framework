playwright-agent-framework

A Playwright test framework layered into config, core runtime, reusable skills, and worked examples. Fixtures compose in one place — src/core/baseTest.ts — and every environment, tenant, and data file feeds into them.

How a test resolves

A spec imports test from baseTest.ts. That file builds envContext from the ENV variable, which selects a config/env module; the resolved environment name then chooses which src/data bundle dataLoader reads. Database and logging fixtures are built independently, and mysql is torn down when the test ends.
